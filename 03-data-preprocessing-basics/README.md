# Data Preprocessing Basics

Practicing the core data preprocessing steps required before feeding data into a machine learning model. Covers handling missing values, encoding categorical data, scaling features, and splitting data into training and testing sets.

## What is covered
- Handling missing values using median imputation
- Encoding text/categorical columns using One-Hot Encoding (pd.get_dummies)
- Feature scaling using StandardScaler
- Train/Test split using sklearn (80/20)

## Concepts practiced
- Why raw data breaks models (missing values, text categories, different scales)
- Overfitting and why train/test split helps catch it

## Dataset
Small custom practice dataset created manually with pandas (age, city, income, bought)
