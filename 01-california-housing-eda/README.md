# California Housing EDA

Exploratory Data Analysis on the California Housing dataset. This includes statistical analysis, visualizations, and correlation analysis to understand relationships between features like median income, house age, and location with the target variable median house value.

## What is covered
- Statistical EDA using pandas (info, describe)
- Visual EDA using histograms
- Correlation heatmap analysis
- Scatter plot analysis between income and house value

## Dataset
California Housing dataset from scikit-learn (`fetch_california_housing`)
