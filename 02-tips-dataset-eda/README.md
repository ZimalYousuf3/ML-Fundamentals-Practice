# Tips Dataset EDA

Exploratory Data Analysis on the Tips dataset from seaborn. This includes statistical analysis, visualizations, and correlation analysis to understand relationships between total bill, tip amount, and party size.

## What is covered
- Statistical EDA using pandas (info, describe)
- Visual EDA using histograms
- Correlation matrix analysis
- Scatter plot analysis between total bill and tip

## Target
Tip amount (predicting how much tip is given based on total bill, size, and other factors)

## Dataset
Tips dataset from seaborn (`sns.load_dataset('tips')`)
